# Homepage trim walkthrough

Branch `homepage-trim`. Screenshots (production mode, JPEG, downscaled) are in `docs/homepage-trim-screenshots/`: `home-before-*` and `home-after-*` at 1280 and 390px.

| 1280px | 9,119px | 5,321px |

## New homepage order
1. **Hero:** one photo (existing hero slots), name, tagline, **Book your stay** and **Explore** (to /explore). The "Stay | Dine | Celebrate | Explore" line is gone.
2. **About:** one block: heading, 2–3 sentences (Content → Business info → "Homepage: About text") and the photo collage (About slot).
3. **Rooms:** one card per active room type: photo, name, short line (the room's description), "from NPR … / night", **Book this room** (`/book?room=<slug>`).
4. **Experiences:** up to four "At Bagaicha" activities as photo tiles (name only), then **See all experiences**.
5. **Dining:** one photo (Dining slot), one line (Content → Business info → "Homepage: Dining line"), link to /dine.
6. **Events & gatherings:** one photo (Events slot, else Conference), one line ("Homepage: Events line"), **Enquire** to `/enquiry?type=EVENT`.
7. **Location:** illustrated map, address, the Nepalgunj distance (from Nearby destinations), **Get directions**, **More about getting here** to /location.

Removed from the homepage only: the Stay/Dine/Explore/Celebrate row, the intro band, the separate conferences section, the activities list, the Google map embed and the nearby list. The embed and nearby list stay on /location; conferences stay on /events. No content tables or pages were changed.

## Footer
The emblem now sits on a cream circular badge (128px on phones, 144px at 1280), emblem at 88/96px inside it, colours unchanged, white wordmark below.

## Content and data
- One additive migration (`20261016090000_homepage_copy`): `business_info.homeAbout`, `homeDiningLine`, `homeEventsLine`. It fills them only where empty.
  - About: the three sentences the homepage already used (brochure wording). Not flagged.
  - Dining: your line, as written. Not flagged.
  - **Events: my draft ("Weddings, celebrations, meetings and trainings, surrounded by nature.") is flagged as a placeholder**, so it shows with a badge in dev and staging and is hidden in production until you edit or review it in Content.
- Section headings (Dining, Events & gatherings, and the existing two-weight headings) stay in `src/config/site-copy.ts`, as before. Button labels are fixed interface text.
- Media → Homepage no longer lists the Stay and Explore slots; their placements remain in the database. The Dining, Events, Conference and Location hints say where each photo is used.

## Things to know
- In production only one "At Bagaicha" activity (Chill pool) has a photo that is cleared for the live site, so Experiences shows one tile there. In dev the other tiles show (flagged photos and a "photo needed" box). It fills to four as photos are confirmed.
- Deluxe Room has no description yet (placeholder in dev, nothing in production), so its card has no short line.
- The `guides` branch changes the same layout file and JSON-LD; expect a small merge there.
- The dev database already has the `guides` migration applied, so `prisma migrate dev` wants a reset here. I applied this migration with `prisma migrate deploy` (SQL generated by `prisma migrate diff`). Nothing was reset.

The dev-only "photo needed" boxes are unchanged and never show in production.
