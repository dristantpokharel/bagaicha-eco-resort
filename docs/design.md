Build/rebuild the website for Bagaicha Eco Resort in Gulariya, Bardiya, Nepal.

I am providing two references:

Bagaicha Eco Resort brochure — this is the primary reference for the brand, visual identity, content direction, colors, typography, photography style and overall aesthetic.
Website audit/design reference — use this to identify the strongest existing UX patterns, information architecture, page structure and interactions that should be retained or improved.

Do not simply recreate the brochure as a website. Use the brochure as the visual DNA and the website reference as the UX/structural foundation. The final result should feel like a polished, modern digital version of Bagaicha that takes advantage of web interaction, responsive layouts and immersive photography.
